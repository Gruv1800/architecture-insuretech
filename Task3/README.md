# Проблемы и риски
### С точки зрения бизнеса

- Упущенные клиенты\прибыль т.к. перечень тарифов и предложений будет не всегда в актуальном стоянии
- Просрочка взаиморасчетов

### С технической точки зрения

- С ростом числа партнеров (страховых компаний) всё чаще будут встречаться ошибки во взаиморасчетах и при оформлении новых страховок, т.к. REST вызовы к сервису ins-product-aggregator будут достаточно "тяжеловесные" (запросы часто будут падать по ReadTimeout или заканчиваться ошибкой, т.к один из партнеров может быть недоступен)
- Нарушен принцип проектирования процесса взаиморасчетов: сервису ins-comp-settlement для проведения расчета необходимо выполнить 2 синхронных REST вызова в смежные сервисы. С ростом RPS это может стать "узким горлышком" всей системы.
